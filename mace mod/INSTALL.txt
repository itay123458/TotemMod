MINECRAFT MACE RECEIVER 1.0.1 - LOCAL INSTALLATION

1. Build with: & '.\mace mod\build.ps1'
2. Close Gorilla Tag.
3. Copy 'mace mod\artifacts\MaceMod.dll' into the game's BepInEx\plugins folder.
4. Start the game with BepInEx 5 and Utilla installed. If the log says
   "Utilla repair ready; restart Gorilla Tag", restart once before joining.
   Installing the included TotemMod.UtillaFix.dll into BepInEx\patchers
   before first launch avoids that extra restart.
5. Join a private modded standard Infection / Tag room to receive compatible
   authenticated developer mace hits.
6. Press F8 for incoming-hit consent, particles and sound settings.

Only Totem Mod's authorized Developer menu equips or configures the mace.
This standalone receiver grants no weapon access, controller/keyboard equip
shortcut, equip button, enchantment controls or weapon size/power controls.
Incoming hits default on; disable Receive developer mace hits to opt out.

Totem Mod is optional for receivers. Both plugins share one runtime when
installed together, with the authorized Developer profile taking priority.
Weapon equipment resets when changing rooms.

To remove: close the game and delete MaceMod.dll from BepInEx\plugins.
Settings live under BepInEx\config\macemod.gtag.rhys.cfg.

Builds use verified Minecraft assets extracted locally without downloads.
Do not redistribute the extracted assets or local DLL embedding them.
This task has not installed the plugin, launched Gorilla Tag or published files.
